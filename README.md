# Crossover

Crossover is the working name for an original 3v3 arcade streetball game in Unreal Engine. Think quick passes, readable team play, exaggerated dunks, and stylized 3D with a retro broadcast feel.

The first playable build is one short half-court match for one player and five bots. You approve what the game should feel like at playable checkpoints. The agents handle implementation, testing, integration, and fixes.

- [First playable build and milestones](docs/SLICE.md)
- [Agent roles, handoffs, and test gates](docs/HARNESS.md)
- [Mac setup and the first engineering ticket](docs/TOOLCHAIN.md)
- [Instructions for agents](AGENTS.md)

Run `python3 scripts/check_foundation.py` from the repository root to check this foundation. Unreal gameplay and its test suite begin with the engine bootstrap milestone.
